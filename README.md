<h1>🌙 <strong>MoonMod — Package Manager Documentation</strong></h1><p></p><h3><em>Self‑Distributed. Language‑Agnostic. Lua‑Native.</em></h3><p></p><p>MoonMod is a <strong>pure‑Lua package manager</strong> designed around one principle:</p><p></p><blockquote><p><strong>Packages distribute themselves.</strong></p></blockquote><p></p><p>There is no central registry, no enforced ecosystem, and no required hosting platform.<br>A MoonMod package is simply a <strong>descriptor file</strong> (<code>&lt;name&gt;.mnmd.txt</code>) that points to its own ZIP payload and its own dependencies. MoonMod retrieves, unpacks, and manages these packages using only <strong>LuaSocket</strong> and <strong>LuaZip</strong>.</p><p></p><p>MoonMod is intentionally minimal, portable, and flexible — capable of distributing:</p><p></p><ul><li><p>Lua libraries</p><p></p></li><li><p>OS‑level utilities</p><p></p></li><li><p>Tools for other programming languages</p><p></p></li><li><p>Game mods</p><p></p></li><li><p>Scripts, assets, configs, plugins</p><p></p></li><li><p>Anything that can be zipped</p><p></p></li></ul><p></p><p>MoonMod does not care what a package <em>is</em>.<br>It only cares that the descriptor follows the MoonMod format (and that it is in non-compiled Lua).</p><p></p><h1>📦 <strong>1. Package Format</strong></h1><p></p><p>A MoonMod package is defined by a descriptor file named:</p><p></p><p>Code</p><pre><code>&lt;package_name&gt;.mnmd.txt
</code></pre><p>This file must contain:</p><p></p><p>Code</p><pre><code>[MoonMod Package]
&lt;ZIP_URL&gt;
&lt;DEPENDENCY_URLS_SEMICOLON_SEPARATED&gt;
"&lt;INSTALL_MESSAGE&gt;"
&lt;VERSION&gt;
</code></pre><h3><strong>Line‑by‑line meaning</strong></h3><p></p><p>LineMeaning<strong>1</strong>Must be exactly <code>[MoonMod Package]</code><strong>2</strong>URL to the ZIP archive containing the package contents<strong>3</strong>Semicolon‑separated list of dependency descriptor URLs (no spaces)<strong>4</strong>A quoted string printed after installation<strong>5</strong>Version number (ignored by logic but stored)</p><h3><strong>Example descriptor</strong></h3><p></p><p>Code</p><pre><code>[MoonMod Package]
https://example.com/mylib.zip
https://example.com/dep1.mnmd.txt;https://example.com/dep2.mnmd.txt
"Installed MyLib successfully!"
1.0.0
</code></pre><h1>📁 <strong>2. Installation Directory</strong></h1><p></p><p>MoonMod installs packages into:</p><p></p><ul><li><p><code>$HOME/.MoonMod</code> (Unix‑like systems)</p><p></p></li><li><p><code>%USERPROFILE%\.MoonMod</code> (Windows)</p><p></p></li></ul><p></p><p>Each package gets its own folder:</p><p></p><p>Code</p><pre><code>~/.MoonMod/&lt;package_name&gt;/
    ├── (unzipped package contents)
    └── &lt;package_name&gt;.mnmd.txt
</code></pre><h1>🧩 <strong>3. Package Philosophy</strong></h1><p></p><p>MoonMod is built on three core ideas:</p><p></p><h2><strong>3.1 Packages Are Self‑Distributed</strong></h2><p></p><p>MoonMod does not host packages.<br>It does not maintain a registry.<br>It does not enforce a central ecosystem.</p><p></p><p>A package <strong>declares where it lives</strong> by embedding its own ZIP URL.</p><p></p><p>This means:</p><p></p><ul><li><p>Anyone can publish a package anywhere</p><p></p></li><li><p>GitHub, GitLab, personal servers, raw file hosts, IPFS, LAN servers — all valid</p><p></p></li><li><p>No gatekeeping</p><p></p></li><li><p>No central authority</p><p></p></li></ul><p></p><p>MoonMod simply follows the URLs.</p><p></p><h2><strong>3.2 Packages Can Contain Anything</strong></h2><p></p><p>MoonMod does not inspect or validate the contents of the ZIP.<br>It only unpacks it.</p><p></p><p>This makes MoonMod suitable for:</p><p></p><h3><strong>Lua packages</strong></h3><p></p><ul><li><p>Libraries</p><p></p></li><li><p>Modules</p><p></p></li><li><p>Frameworks</p><p></p></li><li><p>CLI tools</p><p></p></li><li><p>LuaJIT binaries</p><p></p></li><li><p>Lua scripts</p><p></p></li></ul><p></p><h3><strong>OS‑level packages</strong></h3><p></p><ul><li><p>Shell scripts</p><p></p></li><li><p>Configuration files</p><p></p></li><li><p>Executables</p><p></p></li><li><p>System utilities</p><p></p></li></ul><p></p><h3><strong>Packages for other languages</strong></h3><p></p><ul><li><p>Python modules</p><p></p></li><li><p>C/C++ headers</p><p></p></li><li><p>Rust crates</p><p></p></li><li><p>JavaScript tools</p><p></p></li><li><p>WASM modules</p><p></p></li></ul><p></p><h3><strong>Modding packages</strong></h3><p></p><ul><li><p>Game mods</p><p></p></li><li><p>Asset packs</p><p></p></li><li><p>Plugins</p><p></p></li><li><p>Scripts</p><p></p></li><li><p>Maps, textures, models</p><p></p></li></ul><p></p><h3><strong>Anything else</strong></h3><p></p><p>If it fits in a ZIP, MoonMod can install it.</p><p></p><h2><strong>3.3 Packages Define Their Own Dependencies</strong></h2><p></p><p>Dependencies are simply <strong>other descriptor URLs</strong>.</p><p></p><p>MoonMod recursively installs them.</p><p></p><p>This allows:</p><p></p><ul><li><p>Distributed dependency graphs</p><p></p></li><li><p>Packages hosted across multiple servers</p><p></p></li><li><p>Cross‑ecosystem dependency chains</p><p></p></li><li><p>Lua package depending on a Python tool</p><p></p></li><li><p>Game mod depending on a Lua script</p><p></p></li><li><p>OS utility depending on a shared asset pack</p><p></p></li></ul><p></p><p>MoonMod does not care what the dependency <em>is</em> — only that it has a valid descriptor.</p><p></p><h1>🖥️ <strong>4. MoonMod CLI</strong></h1><p></p><p>MoonMod provides four commands:</p><p></p><p>Code</p><pre><code>moonmod install &lt;descriptor&gt;
moonmod remove &lt;package&gt;
moonmod update &lt;package&gt;
moonmod update all
</code></pre><h2><strong>4.1 </strong><code>moonmod install &lt;descriptor&gt;</code></h2><p></p><p>Installs a package from either:</p><p></p><ul><li><p>A URL to a <code>.mnmd.txt</code> descriptor</p><p></p></li><li><p>A local file path to a <code>.mnmd.txt</code> descriptor</p><p></p></li></ul><p></p><h3><strong>Installation steps</strong></h3><p></p><ol><li><p>Fetch or read the descriptor</p><p></p></li><li><p>Validate <code>[MoonMod Package]</code> header</p><p></p></li><li><p>Read ZIP URL</p><p></p></li><li><p>Download ZIP</p><p></p></li><li><p>Unpack ZIP into <code>~/.MoonMod/&lt;package_name&gt;</code></p><p></p></li><li><p>Save descriptor inside the package folder</p><p></p></li><li><p>Read dependency list</p><p></p></li><li><p>Recursively install dependencies</p><p></p></li><li><p>Print the quoted message from line 4</p><p></p></li></ol><p></p><h3><strong>Example</strong></h3><p></p><p>Code</p><pre><code>moonmod install https://example.com/mylib.mnmd.txt
</code></pre><h2><strong>4.2 </strong><code>moonmod remove &lt;package&gt;</code></h2><p></p><p>Removes a package <strong>only if nothing depends on it</strong>.</p><p></p><p>MoonMod scans all installed descriptors to check for dependency references.</p><p></p><p>If safe:</p><p></p><ul><li><p>Deletes the package folder</p><p></p></li><li><p>Removes all contents</p><p></p></li></ul><p></p><p>If unsafe:</p><p></p><ul><li><p>Aborts with a message indicating which package depends on it</p><p></p></li></ul><p></p><h3><strong>Example</strong></h3><p></p><p>Code</p><pre><code>moonmod remove mylib
</code></pre><h2><strong>4.3 </strong><code>moonmod update &lt;package&gt;</code></h2><p></p><p>Reinstalls the package using its <strong>existing descriptor</strong>.</p><p></p><p>This:</p><p></p><ul><li><p>Re‑downloads the ZIP</p><p></p></li><li><p>Re‑unpacks the package</p><p></p></li><li><p>Reinstalls dependencies</p><p></p></li><li><p>Preserves the descriptor</p><p></p></li></ul><p></p><h3><strong>Example</strong></h3><p></p><p>Code</p><pre><code>moonmod update mylib
</code></pre><h2><strong>4.4 </strong><code>moonmod update all</code></h2><p></p><p>Updates <strong>every installed package</strong> by running <code>update</code> on each one.</p><p></p><h3><strong>Example</strong></h3><p></p><p>Code</p><pre><code>moonmod update all
</code></pre><h1>🔧 <strong>5. Use Cases</strong></h1><p></p><p>MoonMod is intentionally universal.<br>Here are common patterns:</p><p></p><h2><strong>5.1 Lua Ecosystem Manager</strong></h2><p></p><p>MoonMod can act as a:</p><p></p><ul><li><p>Lua library installer</p><p></p></li><li><p>Lua module manager</p><p></p></li><li><p>LuaJIT binary distributor</p><p></p></li><li><p>Script deployment tool</p><p></p></li></ul><p></p><h2><strong>5.2 OS‑Level Package Manager</strong></h2><p></p><p>MoonMod can distribute:</p><p></p><ul><li><p>Shell scripts</p><p></p></li><li><p>System utilities</p><p></p></li><li><p>Config files</p><p></p></li><li><p>Dotfiles</p><p></p></li><li><p>CLI tools</p><p></p></li></ul><p></p><p>Because packages are self‑distributed, MoonMod becomes a <strong>decentralized OS package manager</strong>.</p><p></p><h2><strong>5.3 Cross‑Language Tool Installer</strong></h2><p></p><p>MoonMod can install:</p><p></p><ul><li><p>Python tools</p><p></p></li><li><p>Node.js utilities</p><p></p></li><li><p>Rust binaries</p><p></p></li><li><p>C/C++ toolchains</p><p></p></li><li><p>WASM runtimes</p><p></p></li></ul><p></p><p>Nothing restricts the ZIP contents.</p><p></p><h2><strong>5.4 Game Modding Platform</strong></h2><p></p><p>MoonMod can distribute:</p><p></p><ul><li><p>Mods</p><p></p></li><li><p>Plugins</p><p></p></li><li><p>Assets</p><p></p></li><li><p>Maps</p><p></p></li><li><p>Textures</p><p></p></li><li><p>Scripts</p><p></p></li></ul><p></p><p>Dependencies allow modpacks to be built naturally.</p><p></p><h2><strong>5.5 Internal Company Tooling</strong></h2><p></p><p>MoonMod works well for:</p><p></p><ul><li><p>Private tool distribution</p><p></p></li><li><p>Internal SDKs</p><p></p></li><li><p>Company‑wide scripts</p><p></p></li><li><p>Configuration bundles</p><p></p></li></ul><p></p><p>No central server required — just host descriptors and ZIPs anywhere.</p><p></p><h1>🔒 <strong>6. Security Considerations</strong></h1><p></p><p>MoonMod intentionally does <strong>not</strong> sandbox packages.</p><p></p><p>Users should trust the sources they install from.</p><p></p><p>Recommended practices:</p><p></p><ul><li><p>Use HTTPS URLs</p><p></p></li><li><p>Sign ZIPs externally if needed</p><p></p></li><li><p>Host descriptors on trusted servers</p><p></p></li><li><p>Review descriptor contents before installation</p><p></p></li></ul><p></p><h1>🚀 <strong>7. Why MoonMod?</strong></h1><p></p><p>MoonMod is:</p><p></p><ul><li><p><strong>Decentralized</strong> — no registry</p><p></p></li><li><p><strong>Self‑distributing</strong> — packages define themselves</p><p></p></li><li><p><strong>Universal</strong> — any content, any language</p><p></p></li><li><p><strong>Portable</strong> — pure Lua</p><p></p></li><li><p><strong>Minimal</strong> — only LuaSocket + LuaZip</p><p></p></li><li><p><strong>Recursive</strong> — dependency resolution built‑in</p><p></p></li><li><p><strong>Flexible</strong> — works for OS tools, mods, libraries, anything</p><p></p></li></ul><p></p><p>It’s a package manager that doesn’t try to own your ecosystem —<br>it simply empowers it.</p><hr><p></p>
